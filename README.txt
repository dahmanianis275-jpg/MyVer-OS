Myver (Linux Distro) (Beta)
============================

A fun animated terminal Linux experience that runs inside Windows Command Prompt (cmd.exe).

HOW TO RUN ON WINDOWS (CMD)
---------------------------
1. Download / clone this repo
2. Double-click  Myver.bat

No PowerShell required.

FEATURES
--------
- Animated boot sequence (logo + spinners + progress bars)
- Login screen
- Welcome notepad (greeting, warning, instructions, credits)
- Interactive shell with commands:

  neofetch     System information
  matrix       Matrix rain animation
  ls           List virtual files
  cowsay       ASCII cow (e.g. cowsay hi)
  sl           Steam locomotive
  fortune      Random quote
  version      Show OS version
  reboot       Restart the OS
  clear        Clear screen
  help         List all commands
  exit         Shutdown
